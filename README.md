# CricScore APK (offline, saves on the phone)

1. Create a free account at github.com and make a new repository (private is fine).
2. Upload everything in this folder, including the hidden .github folder, to the repository.
3. Open the Actions tab, choose "Build APK", press "Run workflow" (it also runs on upload).
4. After about 5 minutes open the finished run and download "CricScore-apk" (a zip holding app-debug.apk).
5. Copy app-debug.apk to the phone and open it. If asked, allow "Install unknown apps" for your file manager or browser.

Matches are stored on that phone only. Uninstalling the app or clearing its data deletes them.
